# THE FOCUX Brand Capsule

THE FOCUX uses a gold seal mark: premium, focused, deliberate, and ritual-like.
It is a project/business asset for KAIZEN7 work. It does not replace the
Personal Jarvis app mark, mascot, taskbar icon, or upstream branding.

## Assets

| Asset | Path | Use |
|---|---|---|
| Original vertical logo poster | `assets/kaizen7/the-focux-logo-poster.png` | Documents, brand review, vertical covers |
| Square seal master | `assets/kaizen7/the-focux-mark-1024.png` | Source for UI thumbnails and future exports |
| Frontend square seal | `jarvis/ui/web/frontend/public/kaizen7/the-focux-mark-512.png` | Web UI surfaces owned by KAIZEN7/THE FOCUX |
| Frontend poster | `jarvis/ui/web/frontend/public/kaizen7/the-focux-logo-poster.png` | Web UI brand capsule/detail surfaces |

## Visual Direction

- Gold seal, metallic depth, honeycomb geometry, and centered typography.
- Use on dark, neutral, or restrained gold-tinted grounds.
- Keep enough clear space for the circular seal to breathe.
- Do not use it as the generic Personal Jarvis application icon.
- Do not crop the wordmark away unless the surface explicitly needs a compact seal.

## Operational Meaning

For KAIZEN7, this mark represents disciplined attention:

```text
Luciano decides.
KAIZEN7 focuses.
Agents execute through approved routes.
Projects grow.
Life does not disperse.
```

Use it only when the surface is specifically about THE FOCUX or a KAIZEN7
business capsule connected to THE FOCUX.
